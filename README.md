# Patient Data Management API

A beginner-friendly Patient Data Management API built using **Python and FastAPI**.

This project is created as part of my learning journey with FastAPI and REST API development. Currently, patient data is stored in a JSON file.

## 🚀 Features

- FastAPI-based REST API
- View patient data
- Patient data stored in JSON format
- Simple and clean API structure
- Interactive API documentation using Swagger UI

## 🛠️ Technologies Used

- Python
- FastAPI
- Uvicorn
- JSON
- Git & GitHub
